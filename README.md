# hi.domains

AI Domain Intelligence Platform.

This repository contains the first-stage website framework for `hi.domains`.
It uses Next.js, TypeScript, App Router and Tailwind CSS.

## Current Scope

Included:

- Home page
- Login page
- Signup page
- Dashboard shell
- Pricing page
- Responsive SaaS-style UI

Not included yet:

- AI analysis
- Database
- Payments
- User system
- API routes

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Scripts

```bash
npm run dev
npm run lint
npm run build
```

## Routes

- `/`
- `/login`
- `/signup`
- `/dashboard`
- `/pricing`

## Environment

No environment variables are required for the current phase. See `.env.example`.
